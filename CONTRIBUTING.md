# Contributing

Thank you for your interest in contributing.

## Reporting Issues

If you find a bug or have a feature request, please open an Issue and include:

* A clear description of the problem.
* Steps to reproduce (if applicable).
* Expected and actual behavior.
* Screenshots or logs where helpful.

## Submitting Pull Requests

Before submitting a pull request:

* Discuss significant changes by opening an Issue first.
* Keep pull requests focused on a single change.
* Follow the existing coding style.
* Ensure the project builds successfully.
* Add or update tests where appropriate.

## AI-Generated Code

AI-assisted development is permitted.

If you submit code that was generated or significantly assisted by AI tools, you remain responsible for ensuring that:

* You have reviewed and understood the code.
* The code is correct, secure, and maintainable.
* The code does not knowingly infringe third-party intellectual property rights.
* Appropriate tests are included where applicable.

Please mention any significant AI assistance in your pull request description.

## Code of Conduct

Please be respectful and constructive in discussions.
